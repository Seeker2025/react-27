Шаг 1. Создай Vite + React в текущей папке
Выполни команду:
npm create vite@latest . -- --template react

Обрати внимание на точку . — она означает текущую папку, то есть react-27.
Шаг 2. Установи зависимости
npm install

Шаг 3. Запусти проект
npm run dev


Vite покажет адрес примерно такого вида:
http://localhost:5173/


Открой его в браузере.

Важно: папка react-27 должна быть пустой (или содержать только файлы, которые не конфликтуют
с шаблоном).
Если появится вопрос о перезаписи файлов, не соглашайся, пока не проверим содержимое папки.
